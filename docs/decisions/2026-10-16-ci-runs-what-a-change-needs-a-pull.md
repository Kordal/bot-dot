2026-10-16: CI runs what a change needs. A pull request tests the server when a file outside `android/` (or any Markdown file) changed, and Android when `android/` or `tests.yml` changed; a skipped job counts as passed for a required check. The Android job builds no debug APK (`assembleDebug`): its unit tests and lint compile the app, and the release build packages it. `images.yml` runs no tests, since a commit reaches main only through a pull request whose Tests passed on a branch up to date with main (a branch protection setting), and a build that has started finishes instead of being cancelled by the next push; only the newest push waits. Both of its image scans share the runner's Trivy database. Rejected: skipping the scan of an unchanged image (the release evidence is one scan per digest per run).
