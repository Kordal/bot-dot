2026-11-07: install.sh installs what botdot needs on Debian and Ubuntu with apt-get (as before) and on Fedora and the RHEL family with dnf: Docker from Docker's dnf repository (`fedora`, `rhel`, or `centos` for the rebuilds, which get.docker.com refuses), the same packages by their dnf names (`uidmap` is `shadow-utils`), and gVisor's `runsc` from gVisor's release files (`gvisor.tar.zstd` of `GVISOR_RELEASE`, its sha256 pinned per arch beside the release) into `/usr/local/bin`, as gVisor has no rpm repository. Any other distribution installs them itself and is told what. A kernel older than 5.11, Podman's `docker` and a distribution's own Docker without rootless Docker are refused before anything is installed. CI installs the prerequisites on seven distributions (`make install-prereqs`) and botdot end to end on Debian 12, Fedora 43 and Rocky 10 (`INSTALL_REAL_DISTRO`). Rejected: the release files everywhere (Debian and Ubuntu machines already follow gVisor's pinned apt source, and moving them would replace runsc under running sandboxes), zypper and pacman (Docker has no packages for openSUSE, Arch's rootless Docker is in the AUR), and refusing SELinux (not known to break; untested, so the installer says so).
