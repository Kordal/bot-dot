2026-10-19: The account's computer is made with `--no-healthcheck`: the desktop image's own check asks the control API on port 8000, but each bot's screen has its own ports (its control API on 8100 + its display, `screenPorts`), so Docker called a working computer unhealthy. botdot asks each screen itself when a bot uses it. A computer made before keeps the old check until it is reset. ([#125](https://github.com/Kordal/bot-dot/issues/125))
