2026-10-16: How many of an account's bots' computers run at once is kept in a file only root writes (`<home>/share/share.json`, in a folder root owns), which the account's docker-helper reads (read-only) and enforces: a computer beyond it waits, first come first, and starts when another stops; its run's working line says "Waiting for a free computer". A run stopped while its computer waits starts none. The count is the helper's, inside the account, because only it starts computers; CPU, RAM and disk are the limits that hold whatever runs in the account. Rejected: an environment variable on the helper (a change would restart it, and with it every computer it watches). ([#471](https://github.com/Kordal/bot-dot/issues/471))
