2026-10-18: The desktop image builds from a copy of its base image in this owner's registry (`ghcr.io/<owner>/cua-ubuntu-24.04:<12 hex of the index digest>-<arch>`), not from Amazon's public one, because that one limits downloads without a login and GitHub's shared machines hit the limit at random ("toomanyrequests: Data limit exceeded"). Each platform's build copies only its own part, with `skopeo --preserve-digests`, the first time a base is used, and passes the copy's digest as `BASE`; the Dockerfile keeps Amazon's address for a build elsewhere.
