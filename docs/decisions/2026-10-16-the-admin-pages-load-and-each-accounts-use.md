2026-10-16: The admin page's load and each account's use are measured by root every minute (`install.sh --load`, `botdot-load.timer`, or every minute of the loop without systemd) from outside the accounts: CPU from the unit's `CPUUsageNSec`, RAM from its `MemoryCurrent`, the computers that run from the account's own Docker, the disk from `df` of its mount. Root writes them to files in the front door's `load` folder, which the front door reads (`FRONT_DOOR_LOAD`, read-only) and shows only on the admin page; a reading older than 5 minutes is shown as nothing. An account's file is `account-<name>.json`, so that an account named `machine` is no machine. Rejected: the front door asking systemd or the accounts' Docker (it never runs as root and never looks inside an account). ([#471](https://github.com/Kordal/bot-dot/issues/471))
