2026-10-18: A bot the owner asks to put something on the Board first asks one short question about what they want (with [[choices: …]] for a few short options) and suggests the tile after the answer, unless the request leaves no doubt; this is said in the bot's standing Board note and in `suggest_tile`'s description, not enforced by the server, because only the bot can tell whether a request leaves doubt. A tile a bot suggests because it noticed a repeat (in a run or the weekly review) asks nothing: the owner did not ask, and the suggestion itself waits for their Add; nor does a run for a teammate's message or a task from the Chief, whose reply the owner does not see with buttons. Rejected: a server check that refuses a suggestion with no question before it (a clear request would need a needless question). ([#31](https://github.com/Kordal/bot-dot/issues/31))
