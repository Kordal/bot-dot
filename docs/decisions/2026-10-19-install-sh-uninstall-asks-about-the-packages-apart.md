2026-10-19: `install.sh --uninstall` asks about the packages apart from the typed yes, keeps them under `BOT_DOT_YES=1`, and removes only `runsc` and `docker-ce-rootless-extras` (never `uidmap`, `acl` or `slirp4netns`, which other programs use) after `apt-get -s` shows it would take nothing else, because the installer never wrote down what it installed, so any of them may have been on the machine before botdot. It takes a Linux user as an account's only when it is `botdot-<account>` with the account's folder as its home, leaves botdot's images in the machine's Docker (the installer removes no image by name, and a self-built one is the admin's), and keeps BOT_DOT_DIR whole while an account in it could not be removed. Rejected: `BOT_DOT_YES=1` removing the packages too (an unattended run would take a gVisor another program uses), and `tailscale serve reset` (it would drop Serve settings that are not botdot's).
