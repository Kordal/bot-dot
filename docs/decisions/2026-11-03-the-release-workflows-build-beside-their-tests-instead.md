2026-11-03: The release workflows build beside their tests instead of after them, and only what publishes waits for both: Images' evidence job (and so signing and the `latest` and `accounts-release` tags) needs the tests and the builds, and Android's new publish job needs the tests and the signed build, handed over as an artifact kept one day. A build of a commit whose tests then fail leaves only its per-platform `sha-<commit>-<arch>` tags in the registry, which nothing installs.
