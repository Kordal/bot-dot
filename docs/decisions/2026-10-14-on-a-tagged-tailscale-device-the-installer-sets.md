2026-10-14: On a tagged Tailscale device the installer sets no `BOT_DOT_ALLOWED_USERS` and says that every device on the tailnet can open botdot, because the device's user is Tailscale's `tagged-devices`, a login no person's request carries, so naming it would lock the owner out. The other login users it warns about are read from `/etc/passwd` (a login shell and a UID from `UID_MIN` to `UID_MAX` of `/etc/login.defs`, or 1000 to 59999), so users of a directory service (LDAP, SSSD) are not named. Compose falls back to UTC, not Europe/Warsaw, when `.env` has no `TZ`. ([#432](https://github.com/Kordal/bot-dot/issues/432))
