2026-10-09: The owner's message on its way is the one thing an app draws before the botdot server has said it: from Send it stands in the chat as the app's own bubble, with "Working" under it, and it goes when the server's own copy is there. The two are matched by the message's key, which the app made and the server answers with; when the feed brings the run or the waiting message before the request is answered, by the same words and the same files, counted against how many such messages the chat held before Send. Everything else an app shows it was told by the server. Rejected: waiting for the answer before drawing (a second of nothing after Send, which is what the spec set out to remove); matching by words alone (the same message sent twice would hide the second).
