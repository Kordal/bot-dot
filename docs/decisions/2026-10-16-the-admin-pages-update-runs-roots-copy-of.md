2026-10-16: The admin page's Update runs root's copy of the installer as an update (`--update`), which asks nothing: a question stops it with "Run the installer yourself", and the page says so. Root's copy was changed only by the admin running the installer from the source again (superseded by [ADR 036](../adr/036-the-admin-pages-update-runs-the-installer-of-the-version-it-installs.md)), and with it the four files of the source it checks signatures with (`bin/lib`), so the release key an update trusts is the one the admin last installed. It takes the newest signed release of the repositories `.env` pins, downloads it into the machine's Docker and every account's before it restarts any, then restarts the front door and every account. A failure halfway (rare once everything is downloaded) leaves the accounts it reached on the new version and says so on the admin page; there is no rollback.
