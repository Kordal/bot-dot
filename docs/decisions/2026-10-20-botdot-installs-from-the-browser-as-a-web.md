2026-10-20: botdot installs from the browser as a web app (Chrome and Edge's Install, Safari's Add to Dock and Add to Home Screen). The front door serves the manifest, its icons and screenshots, the touch icon and the offline page itself, without a session, because a browser fetches a manifest without cookies and got a redirect to `/sign-in`; rejected: `crossorigin="use-credentials"` on the manifest's link, which browsers handle unevenly and which would still leave the signed-out sign-in page uninstallable. The service worker is registered on every load and caches one page, "No connection to botdot", for a page that fails to load; nothing of the app or the API is cached, so nothing stale is ever shown. Settings shows "Install app" only where the browser offers it (`beforeinstallprompt`) or in Safari, with the way there. ([#163](https://github.com/Kordal/bot-dot/issues/163))
