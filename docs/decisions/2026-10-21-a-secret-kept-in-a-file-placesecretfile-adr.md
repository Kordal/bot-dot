2026-10-21: A secret kept in a file (`place_secret_file`, ADR 051) is allowed per place, the bot, its entries, the template, the target and its SSH key, the path, the mode and the owner together, not per entry: a changed mode, path or text is a new card, and a rewrite of the same place after the secret changed in the Vault is not. The card has one Allow (for that place, until the owner removes the file), not "Allow once": a file written once is on disk until removed anyway.
