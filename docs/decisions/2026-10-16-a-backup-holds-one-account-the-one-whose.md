2026-10-16: A backup holds one account, the one whose botdot server made it, since each account has its own data and vault key; its manifest names the account and its download is named `bot-dot-<account>-<date>.bdb`. A restore goes into the account that uploads it. The Android app downloads a backup with its own session through Android's download manager: behind the front door the phone's browser has no session and would get the sign-in page. ([#473](https://github.com/Kordal/bot-dot/issues/473))
