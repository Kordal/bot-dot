2026-10-16: The front door passes a call on with only its key, its body's headers, `Host` and `User-Agent`, and sets `X-Forwarded-For` to the client itself: a Tailscale login is dropped, because on a public install anyone can write one, so a refused call keeps no `login` any more. A call on botdot's own port is refused whoever sends it (`refused origin`), which replaces the tailnet, Funnel and "from this machine" checks. ([#472](https://github.com/Kordal/bot-dot/issues/472))
