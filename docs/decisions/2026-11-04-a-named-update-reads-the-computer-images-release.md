2026-11-04: A named update reads the computer image's release by the server's source revision (`accounts-release-<revision>`), not by a second digest in the request: the image workflow builds and signs both images from the same commit, so one digest names the whole version. An install records the signed server release's number as `BOT_DOT_RELEASE` in the front door's `.env`; a machine installed before it has none, and its first named update can't be refused as older (#979).
