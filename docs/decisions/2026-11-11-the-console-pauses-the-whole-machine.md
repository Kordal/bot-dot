2026-11-11: The fleet console pauses a managed machine as a whole, with root's `SUSPEND` and `RESUME`, not one account at a time: it suspends a customer, and a managed machine is one customer's (ADR 154). Root's step has the front door mark every account suspended or resumed (`node front-door.js suspend|resume --by console`), then settles each account as for the admin page's Suspend, so the owner gets the same paused answer and the machine stops the same Docker. It reports one file, `status/suspend.json`, which the agent's heartbeat carries, so the console can see the machine matches its customer and ask again when it doesn't. Rejected: `SUSPEND-<account>` per account (the console would have to track each account's state, and an account it didn't know of would stay open), and the console writing the front door's data itself (the front door owns it).
