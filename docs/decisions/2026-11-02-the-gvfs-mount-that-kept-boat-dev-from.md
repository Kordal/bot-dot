2026-11-02 (#901): The gvfs mount that kept boat.dev from saving a machine came back after #812's one-time unmount, so it is kept away at every level: an apt pin keeps `gvfs-fuse` off, a per-user D-Bus service file stops `browser`'s session bus starting `gvfsd`, the bridge sets `GIO_USE_VFS=local` and `GVFS_DISABLE_FUSE=1` for every Camoufox it starts (the bridge is the only thing that starts one, which answers the objection in the 2026-10-30 line), and botdot takes any FUSE mount under `/home/browser` off before each start of the screen and each stop. Not done: masking gvfs for the machine's own user, whose desktop may use it, and installing boat.dev's command line on the machine: the kit writes the machine's id to `/opt/botdot/sandbox-id` instead. The owner hears of a machine boat.dev can't save as a notification (`boat_unsaved`), not only the admin page, which shows it in red.
