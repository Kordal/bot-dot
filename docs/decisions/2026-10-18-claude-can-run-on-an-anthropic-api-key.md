2026-10-18: Claude can run on an Anthropic API key as well as a subscription (the follow-up named on 2026-10-14), because someone with only a key could not use botdot. The key is kept in `data/claude-key.json`, encrypted with the Vault's key as the Composio key is, with which of the two runs use; saving a key picks it, and it is checked with Anthropic first (a list of one model, `BOT_DOT_ANTHROPIC_API_URL` only for tests). It reaches Claude Code only as `ANTHROPIC_API_KEY`, in `identity.runAs` and the broker's allow list, and only while the owner picked it, with no subscription token beside it. `loggedIn` means "bots can run", so on the key it is true whatever the subscription is, and older apps keep working. Runs going on when the owner switches or removes the key finish on what they started with. Like the subscription's access token today, the key is in the environment of the bot's Claude Code, so a bot's own commands could read it. Rejected: stopping every run on a switch (as a sign-out does; nothing is wrong with what they run on), an `apiKeyHelper` script (a file the bot's user must read, no safer), and keeping the key in the account's `.env` (the owner could not set it from the apps). ([#35](https://github.com/Kordal/bot-dot/issues/35))
