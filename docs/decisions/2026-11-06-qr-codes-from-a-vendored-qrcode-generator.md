2026-11-06: Upload from phone's QR code (ADR 165) is drawn by the server with an unchanged copy of qrcode-generator 1.4.4 (Kazuhiko Arase, MIT, one file) in `vendor/qrcode-generator/`, not a QR encoder of botdot's own: encoding (Reed-Solomon, masks, versions) is easy to get subtly wrong and hard to test, and the library has done it for fifteen years without dependencies. The server keeps only `isDark` of it and writes its own SVG (one path), so the page needs no script of the library.
