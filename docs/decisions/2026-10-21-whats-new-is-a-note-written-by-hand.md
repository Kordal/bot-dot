2026-10-21: What's new is a note written by hand per release in `whats-new/` (Bart's choice; not built from PR titles, not written by the Chief), let into the image by a line of its own in `.dockerignore`, which is an allowlist; a test keeps that line. The account keeps the id of the newest note it saw in `data/whats-new.json`, not in `settings.json`, whose `update` takes only known settings and whose `GET` the apps read as settings. An account's server that starts without a seen id takes the newest note there is as seen (at the start, not at the first ask, so an account nobody opens between two updates still gets the second one's note), so a new account and the release that brings What's new show nothing, and that release's own note is never shown. A page left open across an update asks again only when it is loaded again. Rejected: one pop-up per device (the issue asks once per person). ([#219](https://github.com/Kordal/bot-dot/issues/219))
