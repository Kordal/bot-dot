2026-10-19: What a bot uses of the account's computer (#109) is counted inside it by `deploy/desktop/botdot-usage`, run as root on each look: a process is the bot's whose screen is in its environment (`SCREEN`, or `DISPLAY` `:n`), on its command line, or its parent's; memory is resident memory, so shared pages count in each process, and CPU is measured over half a second. Not cgroups per bot: every bot runs in one container as one user, so nothing else tells them apart. The apps show each bot's use and nothing of the account's share or total, which stay on the admin page (AGENTS.md rule 5).
