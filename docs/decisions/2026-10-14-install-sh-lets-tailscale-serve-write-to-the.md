2026-10-14: `install.sh` lets `tailscale serve` write to the screen instead of capturing its output, because when Serve is not enabled on the tailnet it prints the link to enable it and waits for that, which a captured or discarded output turns into a silent hang. A failed Serve leaves `BOT_DOT_ALLOWED_HOSTS` unset, so the next run tries again. Rejected: capturing the output and printing it only on a failure. ([#432](https://github.com/Kordal/bot-dot/issues/432))
