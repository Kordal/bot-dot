2026-11-22: when the relay revokes the machine's token, Feedback is hidden where it would go to the developers (`feedbackTo` is `null`, not `"admin"`), the front door keeps asking for statuses at the usual times and takes a `2xx` answer as the token being taken again, and a deleted account's report ids are kept in `feedback-relay.json` until the relay deletes them, because an owner who was told "the developers read it" must never find their report on an admin page unsaid, a machine can't tell from silence that an operator unblocked it, and a deletion that fails has to survive a restart. Rejected: falling back to the admin page (the owner's consent was to the developers, ADR 259), a manual "try again" on the admin page (one more control for something the machine can see itself), and an in-memory deletion queue (a restart would lose a deletion promised to the owner).
