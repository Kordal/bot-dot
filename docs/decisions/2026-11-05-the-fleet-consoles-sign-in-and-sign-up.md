2026-11-05: The fleet console's sign-in and sign-up links (#985) are asked with root's own request files (`SIGN-IN-<account>`, `SIGN-UP`) and made by the front door's own command (`--by console`), which root's step runs in its container, rather than by a route of the front door: the product gets no API for the console (ADR 154), and a request the front door made is refused as `BACKUP`'s is. The audit store reads its file again when another process appended to it, so the command's entries are listed by the running front door.
