2026-10-16: The front door's passkeys are checked by botdot's own code (`lib/front-door/webauthn.js`, with a CBOR reader of its own), not a library, because botdot has no dependencies and WebAuthn's server half with `attestation: "none"` is a hash, a signature and a few fields. It takes ES256, EdDSA and RS256, and refuses a passkey whose sign count did not go up where the authenticator counts.
