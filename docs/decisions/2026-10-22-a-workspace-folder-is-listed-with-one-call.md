2026-10-22: A Workspace folder is listed with one call of the privilege worker (`listDirSync`, and `countTreeSync` for a delete's confirmation, `lib/principal-fs-worker.js`), not a `lstat` per entry, because each brokered call starts a process: 1,000 entries one by one would take minutes. Both are read-only, never follow a link, and stay inside the principal's own folder like every other operation.
