2026-10-22: A bot's Workspace in its settings (#296) has two roots: its workspace on the botdot server (`data/workspaces/<bot>`, where its runs work and `uploads/` lives), fully managed, and its folder on the account's computer (`/workspace/<bot>`), only listed, opened, downloaded and deleted in, through fixed scripts run as box with `runShell` while the computer runs, never started for a listing. The server root is the one that always exists, whether the bot uses the computer or not; uploading, renaming and moving on the computer would need writes there botdot does not yet make, so they wait.
