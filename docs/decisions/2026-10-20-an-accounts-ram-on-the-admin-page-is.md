2026-10-20: An account's RAM on the admin page is its unit's memory less its file cache (memory.stat `file` minus `shmem`), as the machine's RAM is total less available: before, an account counted the cache and showed 6.6 GB while the whole machine used 2.5 GB. Its shared memory stays in, since under gVisor that is the sandboxes' own memory, which can't be taken back without swap; the 90% mark (#150) reads the same number (#126).
