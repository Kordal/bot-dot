2026-10-14: A self-built botdot server is supported without a signature: its images are named without a registry, compose uses them for the server and the bots' computers, and Settings tells it to update by pulling the source and building again. The signed images keep the pinned key, and `install.sh` checks their signature on the first install too. Rejected: a key each fork sets for itself (later, if forks publish images).
