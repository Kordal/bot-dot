2026-10-10: The browser bridge's request handler (`BridgeHandler` in `deploy/desktop/camoufox-browser`) drops an answer to a client that has gone (`BrokenPipeError`, `ConnectionResetError` on the write) without a word, and answers an empty, unreadable or non-object request (`{}` too) itself with `ok: false`, never queuing it to the browser's thread, because the already-running check (`bridge_running()`, a bare connect) left a traceback in `bridge.log` on every second start and its empty request ran on the browser's thread. Any other failure in the handler is still reported. Rejected: making the check send `{"op": "where"}` and read the answer (a real client that gave up after its timeout would still leave a traceback). ([#360](https://github.com/Kordal/bot-dot/issues/360))
