2026-11-22: The Feedback relay's protocol is `POST /v1/install` for the token and `PUT /v1/reports/<front door's id>` (the id in the address, so it is the idempotency key and the body is exactly `{ kind, text, app, version, screenshots }`); the front door replaces the account's name with `[account]` and its bots' names with `[bot]` (whole names, longest first, none of one character), sends only after its botdot server named its bots (else the report waits), takes a loopback `http` relay only for the tests, and defaults the address to `https://feedback.botdot.app`, because ADR 259 left the wire to bot-dot and a body without the id keeps "nothing else of the machine goes with it" checkable by one assertion.
