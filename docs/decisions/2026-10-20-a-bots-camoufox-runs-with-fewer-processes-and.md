2026-10-20: A bot's Camoufox runs with fewer processes and small caches (`firefox_user_prefs` in `deploy/desktop/camoufox-browser`): site isolation off and one content process for every site (`fission.autostart`, `dom.ipc.processCount` 1), no spare content process (`dom.ipc.processPrelaunch.enabled`), no Socket process (`network.process.enabled`), a 16 MB memory cache and no pages kept for Back. Under gVisor the guest sees all of the machine's RAM, so Firefox sizes its caches from it and never feels short, and what it takes the account doesn't get back while it runs. One bot's browser holds only its owner's sites, so site isolation guards little there. Not done: the extensions process inside the main one (`extensions.webextensions.remote`, unsupported on desktop Firefox) and no fork server or media processes (their memory is mostly libxul, shared with the others). The 3.4 GB measured on hq was resident memory summed over 8 processes (botdot-usage), which counts their shared libxul in each, so the browser's real cost is less than that sum. ([#152](https://github.com/Kordal/bot-dot/issues/152))
