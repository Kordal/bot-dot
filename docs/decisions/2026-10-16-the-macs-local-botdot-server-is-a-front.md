2026-10-16: The Mac's local botdot server is a front door with `FRONT_DOOR_ONE_ACCOUNT=owner` at `http://localhost:<port>` (a passkey can't belong to 127.0.0.1). Its one passkey is made with `FRONT_DOOR_SETUP_KEY`, a secret the app makes at setup and drops once the passkey is made, which opens the one account's sign-up page until the account exists; no sign-up link is printed or opens. The front door runs in its own container as botdot's server user (60000), the only user botdot's socket lets in; the privilege supervisor gives that user the socket's folder in a shared volume. Publishing the local botdot server on the tailnet for the phone ("Your phone") is gone from the Mac app until it has a design behind one name: the front door answers as localhost only. (#469)
