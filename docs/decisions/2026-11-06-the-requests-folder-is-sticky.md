2026-11-06: The front door's `requests` folder is `1770` (sticky) on every install and update, and `by_root` takes a request as root's only when it is a regular file, not a link, owned as `BOT_DOT_DIR` is and with one name, because the front door's group may write there: without the sticky bit the front door could rename a request root made (the fleet console's agent writes `BACKUP`, `UPDATE`, `SWITCH-<account>`, `KEYS` and others there as root) to `RESTORE` or `ROLLBACK-<account>`, which still passed as root's by its owner, and run a restore that waits for the operator's passkey on the console without it. Request names and formats are unchanged. Rejected for now: a folder of root's own for root's requests (a protocol change for the console's agent, ADR 154). (Fleet console audit, 2026-11-06)
