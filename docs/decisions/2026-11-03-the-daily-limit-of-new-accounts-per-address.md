2026-11-03 (#913): The daily limit of new accounts per address counts an IPv6 address as its /64, since one home or one server holds a whole /64 and a script would take a new address for each account; IPv4 counts the address itself. The machine's own address (127.0.0.0/8, ::1) isn't limited: behind Caddy or Tailscale Serve every outside sign-up carries its own address, so loopback is only the install, `npm start` or a test. An `access` block never stops the admin's own session or the admin signing in (a right passkey of another account from there gets no session), on top of refusing a block of the admin's own address, so that an admin whose address changes into a blocked range keeps the admin page. It also stops calls from there, since `access` means nothing from that address. A refusal is an audit entry once an hour for each address and kind, as #912's full machine, so that a page and its files asked again and again don't fill the log. The limit sits beside the maximum in the capacity form (one Save, each value sent only when it changed), and a block's end is picked as 1, 7 or 30 days or none instead of a date.
