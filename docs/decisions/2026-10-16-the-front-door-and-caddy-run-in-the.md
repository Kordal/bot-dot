2026-10-16: The front door and Caddy run in the machine's own Docker under runc (the front door as its own system user `botdot-door`, on the host network at `127.0.0.1:4700`); only the accounts get rootless Docker and gVisor. Caddy is pinned by digest (`caddy:2.10.2`). Each account's rootless Docker is the systemd unit `botdot-account@<name>`, with the `cgroupfs` driver, because the `systemd` driver needs a user session's systemd, which a system unit doesn't have; without systemd (a container, as in `make install-real`) the installer starts it with `su` and says that it won't come back after a restart. ([#466](https://github.com/Kordal/bot-dot/issues/466))
