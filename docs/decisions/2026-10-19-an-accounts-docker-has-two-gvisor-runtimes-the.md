2026-10-19: An account's Docker has two gVisor runtimes: the default `runsc`, which every bot's computer runs under, without `--host-uds`, and `runsc-uds`, with `--host-uds=all`, which `compose.yaml` names for the botdot server and its Docker helper alone, since only they meet through Unix sockets in their mounts. A computer could otherwise reach any host socket a mount gave it. Both keep `--net-raw` (a computer's firewall) and `--overlay2=none` (#68). The Caddyfile of a public install sends `Strict-Transport-Security: max-age=31536000`, without `includeSubDomains`, since the owner's other subdomains aren't botdot's. `/connectors/done` carries the server's CSP and closes itself no more: a tab the page didn't open can't be closed by its script anyway. A body that is not JSON is a 400. ([#72](https://github.com/Kordal/bot-dot/issues/72))
