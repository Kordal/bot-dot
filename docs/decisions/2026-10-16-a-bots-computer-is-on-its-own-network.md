2026-10-16: A bot's computer is on its own network and its firewall is set by root inside it, under gVisor and runc alike (`botdot.network-version=2`): one way to start a computer, not one per runtime. Only the firewall script differs: runc keeps its rules for what comes in, with conntrack; gVisor's legacy iptables filter only what leaves, and drop what leaves botdot's ports on any interface but loopback, so nobody outside reaches a computer's control or screen without conntrack, with LAN access too. A computer made the old way (`botdot.network-version=1`) is kept but stopped with "Export its files and reset it", as ADR 028 has no migration. Rejected: keeping the quiet network container on runc (two ways to make a computer, and gVisor cannot use it). ([#475](https://github.com/Kordal/bot-dot/issues/475))
