2026-10-18: A Docker helper names its bots' computers `botdot-<Compose project>.<bot id>` (their networks `…-network`), labels them `botdot.instance=<project>`, and lists, counts and erases only the containers with its own names, because two `compose.single.yaml` apps on one Docker host shared one name space and saw, counted and could touch each other's computers. A project name and a bot id hold no dot, so two names never meet. As it starts, the helper renames the computers from before (`botdot-<bot id>`) to its own names, so they keep their files; with two apps on a host that had one, the first helper to start takes them. Without a helper (the Mac, tests) names stay `botdot-<bot id>`. Rejected: owning computers by the label alone (a renamed computer from before has no such label, and a label cannot be added to a container). ([#19](https://github.com/Kordal/bot-dot/issues/19))
