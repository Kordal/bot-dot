2026-10-22: A code block's Copy (#285) is drawn by the Markdown renderer itself, so every fenced block gets it wherever Markdown is drawn (chats, the document viewer, a skill), except in a reply still being written (its code may be cut short) and on a tile (a tap runs the tile). On the web the page's copy handler copies the `textContent` of the block's `<pre>` at the press, not a second copy of the text in `data-copy`: the text is in the page once, and it is the text as written without trusting an escaped attribute. The button sits in a column of its own beside the `<pre>`, inside a box around it, so a long line never runs under it and a diagram drawn in the `<pre>`'s place keeps it and copies its source. With a mouse it shows on hover or focus; on a touch screen it is always shown. Android copies `Block.Code`'s text to the system clipboard (`copyToClipboard`, shared with hold-to-copy). ([#285](https://github.com/Kordal/bot-dot/issues/285))
