2026-10-23: A web page left open across an update loads itself again (`public/fresh.js`), keyed on `web` in `GET /api/version`, a hash of the page's own files, rather than the image's revision: an update that changes only the server reloads no page, and a self-built image or a source checkout without a revision is still seen. It reloads with no banner, only when nothing would be lost (no dialog, no text field in use, no unsent text); What's new then says what changed. The static files' ETag became their content's hash instead of size and time. Rejected: a service worker that caches the app (it would add the staleness this fixes), and an "Updated, reload" bar (one more line to read for what can happen by itself).
