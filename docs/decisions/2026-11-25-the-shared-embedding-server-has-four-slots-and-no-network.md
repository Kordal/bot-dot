2026-11-25: The shared embedding server (ADR 273) has four slots (`BOT_DOT_EMBED_SLOTS`) and its threads are capped as an account's own were, half the CPUs and at most four (`BOT_DOT_EMBED_THREADS`), and its container has `network_mode: none` with llama-server on its own loopback, because four slots let one account's indexing and another's lookup run at once without more than a few accounts waiting for each other, its CPU is outside every account's share and so must not take the machine, and with no network the sockets are its only way in. Rejected: llama-server on the machine's loopback or a Docker network (anything on it could then reach it without a socket), and one thread per CPU. Not measured: its memory with four slots, which ADR 028's measurement of one slot stands in for. (#1704)
