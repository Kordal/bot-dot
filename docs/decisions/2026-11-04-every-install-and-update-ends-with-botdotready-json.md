2026-11-04: Every install and update ends with `BOTDOT_READY {json}` (#981), after the prose and, on a local install, after `BOTDOT_LOCAL`, which the desktop app finds on any line. Its `signUp` is the install's link to the admin's account only: an update makes no link (a new one on every update would pile up open links), and a local install leaves it out, since its setup key is printed on `BOTDOT_LOCAL` alone (ADR 136) and an older desktop app shows every other line in its log. `accounts` lists the account folders the run leaves with a `compose.yaml`, the admin's included before its sign-up.
