2026-11-02: Desktop app releases (#883): the updater's files are signed with Tauri's own minisign update key, not botdot's ECDSA release key, because Tauri's updater checks only its own format. The private key and its password are the repository secrets `TAURI_SIGNING_PRIVATE_KEY` and `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`, made on the owner's Mac and backed up in its login keychain ("botdot desktop update key"); the public key is in `desktop/src-tauri/tauri.conf.json`. Not the `release` environment, which allows `main` only and so would refuse a tagged release. The builds (`desktop.yml`, which pull requests run) never hold the key: `desktop-release.yml` signs what they hand it in a job of its own. The manifest is in the release `desktop-latest`, not under GitHub's "latest" release, which is the Android app's. Windows ARM64 is cross-built on `windows-latest`.
