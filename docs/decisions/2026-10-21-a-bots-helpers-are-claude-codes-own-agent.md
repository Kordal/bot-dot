2026-10-21: A bot's helpers are Claude Code's own Agent tool inside its one run, as the permission "use helpers" (`Agent` and `Task`, off by default; Bart's choice), not copies of the bot: a copy would break ADR 011's one run at a time, spend the usage limits unseen and clash in a shared repository. The guidance is in a bot's prompt only while it has the permission, and gives code helpers a git worktree each. Unlike web access and commands, a Chief's change that adds `Agent` does not wait for the owner: a helper only has the tools the bot already has. A bot without it is not told so in "Switched off for you", so it does not ask for helpers for every task. A run's Details already list each helper as its `Agent` call with what it was asked (`description`), so the page adds no words of its own (ALV-004). That helpers keep no notes is the bot's instruction, not a lock: a helper gets the run's tools, its memory tools among them, and Claude Code gives a run no way to take tools from its helpers alone.
