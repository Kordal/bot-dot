## Full description (4000): 1156

```
botdot은 채팅으로 움직이는 AI 봇 팀을 만들어 주는 오픈 소스 소프트웨어 botdot의 Android 앱이에요.

봇을 직접 설정할 필요가 없어요. 비서실장에게 필요한 일을 말하면, 그 일을 맡을 봇을 만들어 실행하고 결과를 알려 줘요. 봇마다 하나의 일을 맡고, 각자의 안내, 도구, 권한, 파일, 일정, 그리고 절대 하지 않을 일 목록을 가져요.

앱에서 할 수 있는 일
• 각 봇, 그리고 비서실장과 채팅하세요. 어느 앱에서든 파일, 사진, 텍스트를 채팅으로 공유할 수 있어요.
• 확인 필요: 스크립트, 로그인, 위험할 수 있는 작업은 무엇을 실행할지 정확히 보여 주고 승인을 기다려요. 앱이나 알림에서 바로 승인하거나 거절하세요.
• 보드: 읽지 않은 메일, 다음 회의, 방 온도처럼 봇이 계속 업데이트하는 실시간 값을 스위치와 목록과 함께 보여 줘요.
• 그룹: 봇 2~6개를 한 채팅에 모으세요. 한 번 쓰면 봇들이 답하고 서로 일을 넘겨 줘요.
• 프로젝트: 하나의 목표, 리더가 있는 봇 팀, 팀 채팅, 셀 수 있는 목표, 할 일 캘린더.
• 페이지: 봇이 페이지를 써 주고, 실시간 숫자와 차트로 일정에 맞춰 최신 상태로 유지해요.
• 봇의 컴퓨터: 컴퓨터를 쓰는 봇마다 내 서버나 외부 가상 PC에 자기 화면과 브라우저를 가져요.
• 봇이 답하거나, 일을 마치거나, 확인이 필요할 때 알림을 보내요. 중간에 푸시 서비스 없이 내 botdot에서 바로 와요.

botdot 계정이 필요해요
앱은 botdot 서버에 연결되며, 서버가 없으면 아무것도 표시하지 않아요. 명령 하나로 내 Linux 서버나 VM에 botdot을 설치하거나(오픈 소스, MIT 라이선스: github.com/ladrok/bot-dot), botdot 서버 관리자가 준 계정을 쓰거나, botdot.app에서 호스팅을 받으세요.

AI 계정
모든 봇은 Claude Code로 실행돼요. 각 계정은 자신의 Claude 구독이나 Anthropic API 키로 로그인하거나, 직접 고른 다른 모델 제공자를 써요. botdot은 독립 오픈 소스 프로젝트이며, Anthropic이 만들거나 Anthropic과 제휴한 제품이 아니에요.

개인정보
앱은 내가 로그인한 botdot 서버와만 통신해요. 분석, 광고, 추적이 없어요. 로그인은 내 서버 자체 페이지에서 패스키로 해요.
```
