## Full description (4000): 895

```
这是 botdot 的 Android 应用。botdot 是开源软件，给你一支用聊天指挥的 AI 机器人团队。

你不用手动设置机器人。告诉幕僚长你需要什么，它就会为这件事创建一个机器人，运行它，并向你汇报。每个机器人只负责一件事，有自己的说明、工具、权限、文件和时间安排，还有一份它绝不做的事的清单。

在应用中你可以
• 和每个机器人以及幕僚长聊天。从任何应用把文件、照片和文字分享到聊天中。
• 待你处理：脚本、登录信息或任何有风险的操作都会等你确认，并准确显示它要运行的内容。在应用中或直接在通知里批准或拒绝。
• 看板：机器人实时更新的数值，比如未读邮件、下一场会议或房间温度，旁边还有开关和列表。
• 群组：把 2 到 6 个机器人放进一个聊天。写一次，它们就会回答，并把工作交给彼此。
• 项目：一个目标，一支有负责人的机器人团队，一个团队聊天，可计数的目标和待办日历。
• 页面：机器人为你写一个页面，并按时间安排保持更新，带有实时数字和图表。
• 机器人的电脑：每个用电脑的机器人都在那里有自己的屏幕和浏览器，运行在你的服务器或外部虚拟电脑上。
• 机器人回复、完成或需要你时会发通知，直接从你的 botdot 发出，中间没有推送服务。

你需要一个 botdot 账号
应用会连接到 botdot 服务器，没有服务器就什么都不显示。用一条命令把 botdot 安装到你自己的 Linux 服务器或虚拟机上（开源，MIT 许可证：github.com/ladrok/bot-dot），使用 botdot 服务器管理员给你的账号，或在 botdot.app 使用托管服务。

你的 AI 账号
每个机器人都运行在 Claude Code 上。每个账号用自己的 Claude 订阅或 Anthropic API 密钥登录，或使用它选择的其他模型服务商。botdot 是独立的开源项目，并非由 Anthropic 制作，也与 Anthropic 无关联。

隐私
应用只与你登录的 botdot 服务器通信。没有分析，没有广告，没有跟踪。登录使用你服务器自己页面上的通行密钥。
```
