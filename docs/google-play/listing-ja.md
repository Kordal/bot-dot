## Full description (4000): 1193

```
botdotのAndroidアプリです。botdotは、チャットで動かすAIボットのチームを持てるオープンソースソフトウェアです。

ボットを手作業で設定する必要はありません。やりたいことをチーフ・オブ・スタッフに伝えると、その仕事のためのボットを作り、実行し、結果を報告します。ボットはそれぞれ1つの仕事を受け持ち、専用の指示、ツール、権限、ファイル、スケジュールと、決してしないことのリストを持っています。

アプリでできること
• 各ボットやチーフ・オブ・スタッフとチャット。どのアプリからでも、ファイル、写真、テキストをチャットに共有できます。
• 対応待ち：スクリプト、ログイン、リスクのある操作は、実行内容をそのまま示してあなたの承認を待ちます。アプリでも通知からでも、承認・拒否できます。
• ボード：未読メール、次の会議、部屋の室温など、ボットが常に最新に保つ値を、スイッチやリストと並べて表示します。
• グループ：2〜6体のボットを1つのチャットに。一度書くだけで、ボットたちが答え、作業を引き継ぎ合います。
• プロジェクト：1つの目標に、リーダーのいるボットのチーム、チームチャット、数値で測れる目標、やることのカレンダー。
• ページ：ボットがあなたのためにページを書き、ライブの数値やグラフとともにスケジュールどおり最新に保ちます。
• ボットのコンピューター：コンピューターを使うボットは、あなたのサーバーまたは外部仮想PC上に、専用の画面とブラウザを持ちます。
• ボットが返信したとき、完了したとき、あなたの対応が必要なときに通知。プッシュサービスを介さず、あなたのbotdotから直接届きます。

botdotのアカウントが必要です
アプリはbotdotサーバーに接続して使います。サーバーがなければ何も表示されません。自分のLinuxサーバーやVMにコマンド1つでbotdotをインストールする（オープンソース、MITライセンス：github.com/ladrok/bot-dot）か、botdotサーバーの管理者から受け取ったアカウントを使うか、botdot.appでホスティングを利用してください。

AIのアカウント
すべてのボットはClaude Codeで動きます。各アカウントは自分のClaudeサブスクリプションかAnthropic APIキーでサインインするか、選んだ別のモデルプロバイダーを使います。botdotは独立したオープンソースプロジェクトであり、Anthropicが作ったものでも、Anthropicと提携しているものでもありません。

プライバシー
アプリが通信するのは、サインインしたbotdotサーバーだけです。分析、広告、トラッキングはありません。サインインには、あなたのサーバー自身のページでパスキーを使います。
```
