## Full description (4000): 2278

```
botdot adalah aplikasi Android untuk botdot, software open source yang memberimu tim bot AI yang kamu atur lewat chat.

Kamu tidak perlu menyiapkan bot satu per satu. Cukup bilang ke Kepala Staf apa yang kamu butuhkan, lalu ia membuat bot untuk tugas itu, menjalankannya, dan melapor kembali. Tiap bot punya satu tugas, instruksi, alat, izin, file, dan jadwalnya sendiri, plus daftar hal yang tidak pernah ia lakukan.

Yang bisa kamu lakukan di aplikasi
• Chat dengan tiap bot dan dengan Kepala Staf. Bagikan file, foto, dan teks ke chat dari aplikasi mana pun.
• Menunggumu: skrip, login, atau apa pun yang berisiko menunggu persetujuanmu, lengkap dengan apa yang akan dijalankan. Setujui atau tolak di aplikasi, atau langsung dari notifikasi.
• Papan: nilai langsung yang terus diperbarui botmu, seperti email belum dibaca, rapat berikutnya, atau suhu ruangan, dengan sakelar dan daftar di sampingnya.
• Grup: masukkan dua sampai enam bot ke satu chat. Tulis sekali, dan mereka menjawab serta saling mengoper pekerjaan.
• Proyek: satu tujuan, tim bot dengan ketua tim, chat tim, target yang bisa dihitung, dan kalender to-do.
• Halaman: bot menulis halaman untukmu dan memperbaruinya sesuai jadwal, dengan angka dan grafik yang langsung diperbarui.
• Komputer bot: tiap bot yang memakainya punya layar dan browser sendiri di sana, di servermu atau di PC virtual eksternal.
• Notifikasi saat bot membalas, selesai, atau menunggumu, dikirim langsung dari botdot milikmu, tanpa layanan push di antaranya.

Kamu perlu akun botdot
Aplikasi ini terhubung ke server botdot dan tidak menampilkan apa pun tanpanya. Pasang botdot di server atau VM Linux-mu sendiri dengan satu perintah (open source, lisensi MIT: github.com/ladrok/bot-dot), pakai akun dari admin server botdot, atau pakai hosting siap pakai di botdot.app.

Akun AI-mu
Setiap bot berjalan di Claude Code. Tiap akun masuk dengan langganan Claude atau kunci API Anthropic miliknya sendiri, atau memakai penyedia model lain yang dipilihnya. botdot adalah proyek open source independen, tidak dibuat oleh atau berafiliasi dengan Anthropic.

Privasi
Aplikasi ini hanya berkomunikasi dengan server botdot tempat kamu masuk. Tanpa analitik, tanpa iklan, tanpa pelacakan. Login memakai passkey di halaman server milikmu sendiri.
```
