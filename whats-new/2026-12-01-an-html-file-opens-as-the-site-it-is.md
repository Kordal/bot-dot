An HTML file opens as the site it is
- When a bot writes a web page file (.html), opening it in the viewer now shows the finished page, with its scripts running, not its code.
- Source is one tap away on the Rendered / Source switch, and Copy and Download are still there.
- The page runs in a closed box, on an address of its own, and cannot see your account. Only what is inside the file loads: a style sheet or picture beside it does not.
