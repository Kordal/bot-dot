Der Hinweis auf eine neue Version ist eine Karte
- Ist eine neue Version von botdot bereit, zeigt der Chat des Stabschefs sie als eine Karte: der Titel, die Version, wann dein Konto wechselt und eine kurze Liste, was neu ist.
- Die Karte hat einen Button, Karte öffnen, der dich zur Karte in Wartet auf dich bringt, wo Jetzt und Heute Nacht stehen.
- In der Liste sagt der Chat des Stabschefs „Eine neue Version von botdot ist bereit“.
