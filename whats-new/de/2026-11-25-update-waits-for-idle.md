Eine neue Version wartet, bis deine Bots nichts zu tun haben
- Auf einem Rechner mit einem Konto (botdot auf deinem Computer oder ein Server mit einem Besitzer) und auf einem mit Admin startet eine neue Version dein Konto nicht neu, während Bots arbeiten.
- Sie wechselt, wenn deine Bots nichts tun: standardmäßig nachts, nach 04:00 und vor dem Ende deiner Ruhezeiten.
- Das Aktualisieren des Admins lädt die neue Version nur herunter. Jedes Konto wechselt dann von selbst, sodass kein Durchlauf abgebrochen wird.
