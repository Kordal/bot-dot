Eine HTML-Datei öffnet sich als die Website, die sie ist
- Schreibt ein Bot eine Website-Datei (.html), zeigt die Vorschau jetzt die fertige Website mit laufenden Skripten, nicht ihren Code.
- Der Quelltext ist einen Tipp entfernt, über den Schalter Formatiert / Quelltext, und Kopieren und Herunterladen gibt es weiterhin.
- Die Website läuft in einem geschlossenen Kasten, unter einer eigenen Adresse, und sieht dein Konto nicht. Nur was in der Datei selbst steht, wird geladen: ein Stylesheet oder Bild daneben nicht.
