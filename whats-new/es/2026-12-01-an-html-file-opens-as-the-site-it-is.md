Un archivo HTML se abre como el sitio que es
- Cuando un bot escribe un archivo de sitio web (.html), abrirlo en la vista previa ahora muestra el sitio terminado, con sus scripts en marcha, no su código.
- El código queda a un toque, en el selector Formateado / Fuente, y Copiar y Descargar siguen ahí.
- El sitio se ejecuta en una caja cerrada, en una dirección propia, y no puede ver tu cuenta. Solo se carga lo que está dentro del archivo: una hoja de estilos o una imagen al lado, no.
