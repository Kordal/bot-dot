Een HTML-bestand opent als de website die het is
- Schrijft een bot een websitebestand (.html), dan toont de viewer nu de website zelf, met werkende scripts, en niet de code.
- De code is één tik verder, met de schakelaar Opgemaakt / Bron. Kopiëren en Downloaden zijn er nog.
- De website draait in een afgesloten vak, op een eigen adres, en ziet je account niet. Alleen wat in het bestand zelf staat, wordt geladen: een stylesheet of afbeelding ernaast niet.
