Tables in bot replies look the same everywhere
- A table a bot writes in its reply is now drawn like the tables in its answer views, in the app's own look, including the replies already in your chats.
- On the phone, a table is a list of rows: the first cell is the name and the other cells sit under it with their column headings.
- Bold, code and links in a cell still work. A very large table is shown as before, and Copy still gives the table as text.
