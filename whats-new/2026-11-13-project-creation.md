Start a project by talking
- Describe what you want, with optional files or links, and continue in the project's Chief conversation.
- There is no required SWOT, stories or Board design. The Chief asks only what it needs for the next action.
- Review the first step, proposed bots, access and recurring work before approving them. Existing action and login approvals still apply.
- Reopen an interrupted conversation to continue. Projects already in the old setup keep their existing flow.
