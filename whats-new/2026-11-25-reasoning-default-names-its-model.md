Reasoning "Default" says what the model gets
- In a bot's settings and the Chief's, the Reasoning "Default" now names what that bot's model runs with, such as "Default (Medium)" or "OpenCode Go's own", and changes as you pick another model.
- Model's "Default" names the account's default model.
- A provider's model shows its provider first, such as "OpenCode Go · DeepSeek V4.1 Flash · Max", so a narrow row no longer cuts it off.
