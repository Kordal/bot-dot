File HTML terbuka sebagai situs jadinya
- Saat bot menulis file halaman web (.html), membukanya di pratinjau sekarang menampilkan halaman jadinya, dengan skripnya berjalan, bukan kodenya.
- Kodenya tinggal satu ketukan lewat tombol Tampilan / Sumber, dan Salin serta Unduh tetap ada.
- Halamannya berjalan di kotak tertutup, di alamatnya sendiri, dan tidak bisa melihat akunmu. Hanya isi file itu yang dimuat: style sheet atau gambar di sebelahnya tidak.
