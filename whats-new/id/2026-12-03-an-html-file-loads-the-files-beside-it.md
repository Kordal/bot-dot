File HTML memuat file di sebelahnya
- File halaman web (.html) yang kamu buka di penampil kini memuat stylesheet, skrip, dan gambar yang ada di sebelahnya, di foldernya dan folder di bawahnya.
- Yang dihitung hanya file di folder itu: jenis yang boleh ada di halaman, maksimal 300 file dan 5 MB. Folder yang lebih besar, atau berisi tautan, dibuka sebagai satu file saja seperti dulu.
- Tidak ada yang dimuat dari internet, dan halaman tetap berjalan di kotak tertutup serta tidak bisa melihat akunmu.
