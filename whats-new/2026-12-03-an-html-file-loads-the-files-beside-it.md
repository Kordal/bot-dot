An HTML file loads the files beside it
- A web page file (.html) you open in the viewer now loads the style sheets, scripts and pictures that sit beside it, in its folder and the folders under it.
- Only that folder's own files count: the kinds a page may hold, at most 300 files and 5 MB. A bigger folder, or one with a link in it, opens as the one file, as before.
- Nothing loads from the internet, and the page still runs in a closed box and cannot see your account.
