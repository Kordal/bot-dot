The board stays readable in a narrower window
- When the window is narrower than about 960 pixels, for example with the chat open, the board shows its tiles in one column instead of drawing them small.
- Current work, Blockers and Latest replies show whole rows and say how many more there are, instead of cutting the last row in half. This holds on the web page and in the Android app.
- Make a tile taller to see more rows.
