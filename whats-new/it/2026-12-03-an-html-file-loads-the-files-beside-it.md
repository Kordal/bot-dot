Un file HTML carica i file accanto a sé
- Un file di pagina web (.html) che apri nel visualizzatore ora carica i fogli di stile, gli script e le immagini che ha accanto, nella sua cartella e nelle cartelle sotto di essa.
- Contano solo i file di quella cartella: i tipi che una pagina può contenere, al massimo 300 file e 5 MB. Una cartella più grande, o con un link dentro, si apre come il solo file, come prima.
- Non si carica nulla da internet, e la pagina gira ancora in una scatola chiusa e non vede il tuo account.
