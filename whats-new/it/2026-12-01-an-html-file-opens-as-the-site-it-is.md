Un file HTML si apre come il sito che è
- Quando un bot scrive un file di sito web (.html), aprirlo nell'anteprima ora mostra il sito finito, con i suoi script in funzione, non il suo codice.
- Il codice è a un tocco, con il selettore Formattato / Sorgente, e Copia e Scarica ci sono ancora.
- Il sito gira in una scatola chiusa, a un indirizzo tutto suo, e non vede il tuo account. Si carica solo ciò che è dentro il file: un foglio di stile o un'immagine accanto no.
