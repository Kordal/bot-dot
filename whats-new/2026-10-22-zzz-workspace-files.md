Every file in a bot's folder
- A bot's settings have a Workspace next to Files: every file in its folder, not only what you gave it.
- Open a file in the viewer or download it, upload into a folder, make folders, rename, move and delete.
- What botdot keeps there to run the bot is shown read-only, and a delete always says first what goes.
- For a bot that uses the computer, its folder there opens too while the computer is on.
