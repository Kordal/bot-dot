Une note peut nommer un site web
- Un bot peut enregistrer une note sur un site précis, par exemple où se trouve sa connexion ou quel bandeau fermer d'abord.
- Quand le bot ouvre ce site dans son navigateur, la note arrive avec la page : elle ne dépend pas des mots de la demande.
- Elle arrive une fois par site et par exécution, avec les notes du domaine parent du site.
