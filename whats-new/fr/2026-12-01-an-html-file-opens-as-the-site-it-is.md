Un fichier HTML s'ouvre comme le site qu'il est
- Quand un bot écrit un fichier de site web (.html), l'ouvrir dans l'aperçu montre désormais le site fini, avec ses scripts qui tournent, et non son code.
- Le code est à un toucher, avec le sélecteur Mis en forme / Source, et Copier et Télécharger sont toujours là.
- Le site tourne dans une boîte fermée, à une adresse à lui, et ne voit pas ton compte. Seul ce qui est dans le fichier se charge : une feuille de style ou une image à côté, non.
