Boty same logują się do gita
- Git i ssh bota używają kluczy SSH, które mu udostępniasz, nie tylko na jego komputerze.
- Aplikacja GitHub, którą udostępniasz botowi, pozwala jego gitowi klonować i wypychać przez HTTPS, z tokenem, który wygasa w ciągu godziny.
- Nic nie jest zapisywane w repozytorium, a bot nigdy nie widzi klucza.
