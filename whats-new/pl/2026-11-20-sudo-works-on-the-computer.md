Boty mogą instalować programy przez apt
- Bot z komputerem może teraz używać sudo i apt-get install bez hasła, także tam, gdzie piaskownica ignoruje bit setuid, którego sudo dotąd potrzebowało.
- Nadal może instalować programy w swoim katalogu domowym przez botdot-install, a program zostaje po aktualizacji komputera.
