# botdot's words, for translators

The words the interface uses for botdot's own things, and what each one is ([CONTEXT.md](../../CONTEXT.md) has them all, with the words to avoid). Each language has its glossary, `lib/i18n/<code>/GLOSSARY.md` ([Polish's](pl/GLOSSARY.md)): this table's English terms, each with the one word or phrase the language uses for it everywhere: in the dictionary, in What's new and in the Play listing. Write it before the first string, from this file, and keep to it.

How to choose a word:

- **One word per thing, everywhere.** A Board is the same word on a button, in a sentence and in a What's new note. Two English words for two things (a task and a job, a card and a tile) are two words in your language too, even where a dictionary gives one for both.
- **The word people of that language use for that kind of thing in apps they know**, not a word-for-word copy of the English. Look at how phone apps and web apps in the language name a setting, a chat, a notification.
- **Names stay as they are:** botdot (always lowercase), Claude, Claude Code, Gmail, Composio, boat.dev, Bitwarden, Haiku, Sonnet, Opus, GitHub, Google Play. They may take the language's endings where its grammar needs them (Polish: "botdota").
- **Address the owner as a friend would**, the informal "you" where the language has two (Polish "ty", German "du", French "tu", Spanish "tú", Russian "ты"), unless apps in that language never do (Japanese and Korean: polite but plain forms, no honorific excess). Say which in your glossary, with the form of a button ("Save": an imperative, an infinitive or a noun?).
- **Short.** A button or a menu item has room for one to three words; a phone screen is narrow. When the natural translation is long, find a shorter natural one.

| English | What it is in botdot |
| --- | --- |
| botdot | The product. Always lowercase, never translated. |
| bot | One AI worker of the owner's team, shown as a head with a hat. A person's own helper, not a chatbot on a website: choose the word people use for an app's bot. |
| Chief of Staff / the Chief | The one special chat that creates, changes and runs the other bots for the owner. A role, as in a government or a company: the person who runs the boss's staff. Short form "the Chief". |
| Project Manager | The bot the owner picked to talk to all teams of a project. |
| main assignment | A bot's standing task: what it does when nothing else is asked of it. |
| task | What one run of a bot is asked to do (a message, a job's request). Not a job. |
| job / scheduled job | A run of a bot on a schedule, or once, or when called. Not a task. |
| script job | A job that runs a script, without AI. |
| run | One time a bot works: from a message or a job to its reply. |
| Needs you | Everything waiting for the owner's OK, shown as one place. A short heading, as "Waiting for you". |
| card | One thing waiting in Needs you, with its buttons. Not a tile. |
| Board / tile | The owner's one page of tiles (switches, values, lists) for what they use most / one thing on it. Not a dashboard, not a card. |
| keypad / key | The home of a wide window: the team as pages of keys / one bot or group on it. |
| page / Pages | A lasting page a bot writes for the owner (a report, a memo) / where they are listed. Also one part of the keypad. |
| interactive page | A small site a bot built, shown in the app. |
| Vault / Passwords | Where the owner keeps the secrets bots may use without seeing them. The apps call it Passwords. |
| Settings / Updates / Activity / Usage | The screens of those names. |
| What's new | The notes shown once after an update. |
| Connectors / connected apps | The owner's apps (Gmail, Calendar…) a bot may use. |
| Files / Workspace / Keep in mind | A bot's files / its folder / a file whose text comes with every task of the bot. |
| group | One chat with two to six bots, each answering under its own name. |
| shared room / Rooms | A chat where people of several accounts and their bots talk. |
| category | A folder of bots and groups in the list ("Home", "Work"). |
| project | A space beside Home for what the owner works on, with its goal, teams and board. |
| team / lead | The bots of a project that work together / the one bot each team has in charge. |
| standup | A project's three lines per team each workday morning: done, next, blocked. |
| skill / helpers | Instructions a bot can use when they fit / short-lived assistants a bot starts inside its own run. |
| note / pinned | Something the Chief or a bot keeps in mind about the owner / a note that never drops out. |
| teammate | Another bot of the same team or group. |
| account's computer | The one Linux computer every bot of the account works on. |
| External Virtual PC | The account's computer when it runs on boat.dev, a cloud service. |
| working line | The one line under a working bot's chat saying what it is doing now ("Reading nytimes.com"). |
| answer buttons | The short choices under a bot's question ("Yes", "No thanks"). |
| Always allow / Allow once / Decline | The buttons of a card: for good / this time / no. |
| Always approved / Revoke | What the owner let through for good / taking it back. |
| Update now / Update automatically / Keep up to date | The buttons and switches of those names. |
| Open as document / Export | Showing a bot's reply as a page / saving it as a file. |
| Reconnect / Disconnect | Signing a connected app in again / out. |
| Working / Done / Idle / Asks | A bot's state: at work / finished / waiting for nothing / waiting for the owner's answer. |
| Stop | Ends a bot's run now. |
| Saved | A short note that a change was kept. |
| the web page | botdot in a browser, as against the phone app. Choose a word that does not clash with a bot's page. |
| the Android app / the iPhone app / the desktop app | The apps. |
| the owner / you | The person whose bots they are. The interface speaks to them as "you". |
